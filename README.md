# Nacre

A macOS iTerm-like terminal setup for Windows 11.

Built on WSL (Ubuntu). If WSL is not installed, it is installed for you; if it already is, it is used as is.

## Install

Run in PowerShell:

```powershell
irm https://nhahan.github.io/nacre/install.ps1 | iex
```

## Features

- **Split pane left/right**: `Ctrl+Shift+V`

  <img src="assets/split-v.gif" alt="Split pane left/right" width="640">

- **Split pane top/bottom**: `Ctrl+Shift+H`

  <img src="assets/split-h.gif" alt="Split pane top/bottom" width="640">

- **Move between panes**: `Ctrl+Shift+Arrow keys`

  <img src="assets/pane-move.gif" alt="Move between panes" width="640">

- **New window / split / close menu**: right-click the tab bar `+` button

  <img src="assets/menu.gif" alt="Menu on right-click of the tab bar + button" width="640">

- **Copy / Paste**: `Ctrl+C` / `Ctrl+V`

  <img src="assets/copy-paste.gif" alt="Copy selected text and paste it" width="640">

- **Change font size**: `Ctrl+Mouse wheel`

  <img src="assets/font-size.gif" alt="Change font size with Ctrl+Mouse wheel" width="640">

- **New line**: `Shift+Enter`

  <img src="assets/shift-enter.gif" alt="Multi-line input with Shift+Enter" width="640">

- **Switch tabs**: `Alt+1~9`

  <img src="assets/tabs.gif" alt="Switch tabs with Alt+number" width="640">

- **Open folders, files, URLs in Windows**: `open` command

  <img src="assets/open.gif" alt="Open Explorer with open ." width="640">
